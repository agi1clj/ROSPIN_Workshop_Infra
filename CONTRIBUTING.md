# Contributing

Thanks for helping. This repository is a teaching template, so the rule is: keep it simple and keep it working end to end.

1. Open an issue first for anything larger than a typo.
2. Branch, change, and run the checks listed in `AGENTS.md`.
3. Use Conventional Commits: `type(scope): summary` (feat, fix, docs, refactor, test, ci, chore).
4. Open a pull request. CI runs the tests and the build.

AI agents are welcome: they read `AGENTS.md`. You still review every line you commit.
